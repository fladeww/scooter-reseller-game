# 🛴 Перепродажа самокатов и питбайков

Браузерная игра-симулятор: покупай у поставщиков, торгуйся с покупателями, открывай кейсы с рулеткой.

## Как играть

1. Открой [index.html](index.html) в браузере
2. **Склад** — твои самокаты и питбайки
3. **Кейсы** — купи и открой (рулетка)
4. **Поставщики** — торгуйся и закупай товар
5. **Покупатели** — продавай дороже
6. **История** — все сделки
7. **Настройки** — тема, сохранение прогресса

## Особенности

- Торг с ботами
- Редкости: обычный → легендарный
- Уровень и достижения
- Анимация рулетки при открытии кейсов
- Сохранение прогресса (авто + скачать/загрузить файл)
- Темы: тёмная / светлая / неон
- Интерфейс в стиле iPhone

## Запуск

Открой `index.html` в браузере.

**GitHub Pages:** Settings → Pages → Deploy from branch `main` → `/ (root)`.
